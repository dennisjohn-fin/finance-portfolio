\# Renewable Energy — Solar Project Financial Model



A project-finance model for a utility-scale solar asset, built from a Confidential

Information Memorandum (CIM) as part of the Renewable Energy — Solar Project Financial Model case study. The model

forecasts cash flows, structures the capital stack, and evaluates returns through NPV, IRR, payback, and sensitivity analysis.



> \*\*Scope note:\*\* This is a course case study completed as structured practice in

> project finance. The CIM and assumptions are provided by the course; the model,

> validation, analysis, and documentation below are my own.



\---



\## Project Overview



\- \*\*Asset:\*\* Utility-scale solar PV project (CIM-provided specifications)

\- \*\*Model type:\*\* Project finance — debt/equity capital stack, DSCR-based debt sizing

\- \*\*Forecast horizon:\*\* Development → construction → 25-year operating period

\- \*\*Currency:\*\* USD

\- \*\*Outputs:\*\* Cash-flow forecast, capital stack, NPV / IRR / payback,

&#x20; credit metrics, sensitivity tables



\---



\## What the Model Does



1\. \*\*Cash-flow forecasting\*\* — revenue (PPA-based), operating costs, taxes,

&#x20;  and free cash flow across the full project lifecycle.

2\. \*\*Capital-stack structuring\*\* — senior debt sized to a target DSCR

&#x20;  covenant, with equity as the residual claim.

3\. \*\*Return analysis\*\* — project and equity NPV, project and equity IRR,

&#x20;  payback period, and cash-on-cash returns.

4\. \*\*Credit metrics\*\* — minimum and average DSCR across the debt tenor.

5\. \*\*Sensitivity analysis\*\* — sensitivity of PPA, post-PPA and Term length



\---



\## Key Assumptions (from CIM)



| Category | Assumption |

|---|---|

| Capacity | 25 MWdc |

| PPA | $72.75/MWh, escalating at 0%/yr |

| Total capex | $30.54 M |

| Opex | $0.95M/yr, escalating at 2%/yr |

| Debt | 85% of capex, 19-yr tenor, 4.65% interest |

| Target DSCR | 1.35x (P50), 1.00x (P99) |

| Tax rate | 25% |



\---



\## Headline Results



| Metric | Value |

|---|---|

| Project NPV | $1.79M |

| Project IRR | 7.51% |

| Payback period | 9.9 years |
